# Личный агент для hh.ru

Приложение ищет Python-вакансии, проверяет условия, готовит письма и ведёт очередь откликов. Управление — в личном чате Telegram. Оно работает на этом компьютере: при выключении или сне компьютера обработка останавливается.

## Первый запуск

Зависимости уже установлены в этой папке. Откройте **scripts/start.command** двойным щелчком. В меню доступны настройка ключей, привязка Telegram, вход в HH, запуск и проверка настроек.

1. В Telegram откройте [официального BotFather](https://t.me/BotFather), отправьте `/newbot`, задайте имя и свободное имя пользователя бота. Токен сохраните через пункт «Настройка ключей» в меню приложения. Ввод скрыт; присылать токен в чат Codex не нужно.
2. Там же укажите API-ключ, адрес API и название модели. Поддерживается интерфейс Chat Completions с JSON-ответом. Для OpenAI адрес — `https://api.openai.com/v1`; модель задаётся явно. Без ключа доступны поиск и черновики на основе подтверждённых фактов резюме.
3. Выберите «Привязать Telegram». Программа покажет одноразовую команду. Отправьте её своему боту в личный чат. Так приложение запомнит ваш ID без обращения к сторонним ботам.
4. Выберите «Войти в HH». В отдельном окне браузера войдите в свой аккаунт самостоятельно, затем вернитесь в окно программы и нажмите Enter. Используется отдельный профиль; вход из браузера Codex не копируется.
5. Выберите «Запустить агента», затем отправьте боту `/search`. Сначала действует **режим просмотра**: вакансии и письма сохраняются, отправка выключена. `/queue` покажет очередь, `/letter ID` — конкретное письмо.
6. Для реальных откликов остановите приложение, в локальном `.env` установите `HH_LIVE=true`, запустите снова и отправьте `/resume`. Для отправки должны быть настроены ключ модели, Telegram и вход в HH.

Не запускайте для одного бота другую программу с polling/webhook. Один экземпляр агента и один отдельный браузерный профиль защищены локальной блокировкой. Пауза действует на следующую отправку; уже начатая операция записывается с фактическим результатом.

## Команды Telegram

| Команда | Действие |
| --- | --- |
| `/search` | Обойти доступную выдачу и сохранить новые вакансии |
| `/pause` | Остановить следующие отправки |
| `/resume` | Продолжить работу в настроенном режиме; не меняет `HH_LIVE` |
| `/queue` | Первые 20 ожидающих записей и общие количества |
| `/history` | Последние 20 результатов |
| `/letter 123456` | Точное письмо, дополнения и подготовка |
| `/reconcile` | Проверить незавершённые отклики без повторной отправки |
| `/requeue 123456` | Явно вернуть пропущенную вакансию на оценку |
| `/settings` | Показать режим и интервалы без секретов |

## Правила

- Python в направлении вакансии; удалённая работа, без командировок. Несовпадение технологий не блокирует отклик.
- 150 000 ₽ в месяц до налогов или на руки. Вилка подходит, если верхняя граница достигает порога. Без зарплаты нужен явно указанный Middle или выше; одних лет опыта недостаточно.
- Неизвестная валюта, период, неоднозначный грейд или географическое ограничение уходят на уточнение. Автоматического курса валют в этой версии нет.
- Видимое предложение пройти тест для вакансии приводит к пропуску. Тест не открывается. Общая реклама тестов и скрытые блоки не блокируют отклик.
- Неизвестные ответы на анкеты требуют участия пользователя.
- Используется только согласованное резюме `b424f687ff113123eb0039ed1f7a496e413267`. Профиль и видимость резюме не изменяются.
- Модель выбирает подходящие факты и до двух ограниченных утверждений о практическом знакомстве с технологиями из списка. Добавленные утверждения и подготовка показываются только владельцу. Карьерные факты не выдумываются и исходный профиль не меняется. Первая версия формирует письма на русском или английском из проверяемых фраз.

## Восстановление и границы версии

Перед отправкой заново читаются условия вакансии. Намерение отправить сохраняется до нажатия кнопки. После подтверждения сценарий завершается, даже если HH предлагает откликнуться повторно другим резюме. Контрольный отклик на вакансию `137924141` уже внесён как отправленный.

При обрыве связи результат становится «неизвестен», а отправка ставится на паузу. `/reconcile` ищет явное подтверждение на странице вакансии. Отсутствие надписи не считается доказательством неотправленного отклика. Если подтверждения нет, нужно проверить историю HH вручную; автоматически повторить такой отклик нельзя.

Капча, истёкший вход и неожиданная структура сайта останавливают затронутую работу. После ручного входа используйте `/resume` или `/search`. Не применяются обход капчи, скрытые методы HH или экспорт чужих браузерных сессий.

Поиск идёт по доступным страницам, при ограничении дополнительно разбивается по четырём диапазонам опыта. Если предел остаётся или выдача меняется, отчёт отмечает неполный охват. Это не обещание найти буквально все вакансии сайта. По умолчанию повторный поиск — каждые 6 часов при снятой паузе, между отправками — 90 секунд; параметры находятся в `.env`.

Ежедневная сводка показывает состояния очереди, новые результаты и все ещё не включённые в сводку пропуски из-за тестов. Подтверждённые отклики, письма и запросы уточнения приходят отдельно. Анкеты с неизвестными ответами нужно заполнить вручную на HH. Чтение входящих сообщений работодателей и изменение их статусов в этой версии ещё не подключены. При сбое Telegram уведомления остаются в очереди; редкий сбой после доставки может продублировать часть уведомления, но не сам отклик.

После длительного простоя Telegram может поменять последовательность ID обновлений. Если после недели бездействия бот перестал принимать команды, остановите приложение и повторите привязку через `pair`.

Проверки с реальным Chromium выполняются на подставных страницах, без запросов к HH. Формы и основные селекторы также сверены с живым HH через браузер. Автономная отправка именно этим приложением потребует отдельного запуска после настройки ключей и входа; ранее выполненный контрольный отклик был отправлен вручную через управляемый браузер.

## Запуск из терминала

```sh
cd /Users/vll/VLL/projects/job_finder_v2
.venv/bin/python -m hh_agent init
.venv/bin/python -m hh_agent configure
.venv/bin/python -m hh_agent pair
.venv/bin/python -m hh_agent login
.venv/bin/python -m hh_agent doctor
.venv/bin/python -m hh_agent run
```

Установка в новую папку на macOS/Linux с Python 3.9 или новее:

```sh
python3 -m venv .venv
.venv/bin/python -m pip install --upgrade pip
.venv/bin/python -m pip install -r requirements.lock
.venv/bin/python -m pip install -e . --no-deps
PLAYWRIGHT_BROWSERS_PATH=.cache/ms-playwright .venv/bin/python -m playwright install chromium
.venv/bin/python -m unittest discover -s tests
```

Секреты находятся в `.env`, сессия и база — в `.state/`; обе папки исключены из Git. Не публикуйте их и не удаляйте базу ради повторной отправки. Обновляя приложение, сохраняйте `.state/agent.sqlite3` вместе с файлами `-wal`/`-shm` либо делайте копию после остановки процесса.

Детальные правила: [одобренный проект](docs/superpowers/specs/2026-10-19-hh-agent-design.md). Формат Telegram проверен по [официальному Bot API](https://core.telegram.org/bots/api); сохраняемый профиль браузера — по [документации Playwright](https://playwright.dev/python/docs/api/class-browsertype#browser-type-launch-persistent-context); запрос модели — по [официальному Chat Completions API](https://developers.openai.com/api/reference/resources/chat/subresources/completions/methods/create).
