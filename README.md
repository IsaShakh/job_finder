# Личный агент поиска вакансий

Приложение ищет Python-вакансии, проверяет условия, готовит письма и ведёт очередь откликов. Запуск и остановка — на компьютере; Telegram показывает результаты без кнопок управления. При выключении или сне компьютера обработка останавливается.

## Первый запуск

Зависимости уже установлены в этой папке. Токены и ключи задаются в файле **.env** в корне проекта: скопируйте `.env.example` в `.env` и заполните значения. Для входа и запуска откройте **scripts/setup.command** двойным щелчком; после настройки **scripts/start.command** сразу запускает поиск, без меню и команд в Telegram.

1. В Telegram откройте [официального BotFather](https://t.me/BotFather), отправьте `/newbot`, задайте имя и свободное имя пользователя бота. Полученный токен запишите в `.env` как `TELEGRAM_BOT_TOKEN`. Присылать токен в чат Codex не нужно.
2. В `.env` заполните `TELEGRAM_OWNER_ID` — числовой ID вашего личного чата (он же получатель уведомлений). Узнать его можно автоматически: `.venv/bin/python -m job_finder pair` покажет одноразовую команду `/start <код>` — отправьте её своему боту, и программа сама запишет ID. Альтернатива — узнать свой ID у @userinfobot и вписать вручную.
3. Там же укажите модель: `LLM_BASE_URL` (для OpenAI — `https://api.openai.com/v1`), `LLM_API_KEY`, `LLM_MODEL` (модель задаётся явно). Интерфейс — Chat Completions с JSON-ответом. Без ключа доступны поиск и черновики на основе подтверждённых фактов резюме.
4. В меню **scripts/setup.command** выберите «Войти в HH (API, без браузера)». Укажите email или телефон HH и пароль — либо войдите по одноразовому коду из SMS/письма. При необходимости капча показывается картинкой в окне программы. Токен хранится локально в `.state/api-token.json` и обновляется автоматически. Запасной способ «Войти в HH в браузере» использует отдельный профиль браузера; вход из браузера Codex не копируется.
5. Откройте **scripts/start.command** или выберите «Запустить агента» в меню настройки. Поиск и обработка начинаются автоматически. Сначала действует **режим просмотра**: вакансии и письма сохраняются, отправка выключена. `/status` покажет состояние и количества, `/letter ID` — конкретное письмо.
6. Для реальных откликов остановите приложение, в локальном `.env` установите `HH_LIVE=true` и запустите снова. Для отправки должны быть настроены ключ модели, Telegram и вход в HH. Telegram не переключает этот режим.

Чтобы остановить поиск и обработку, нажмите **Ctrl+C в окне скрипта**. Для продолжения запустите скрипт снова. Уже начатая отправка сохраняется для проверки при следующем запуске. Не запускайте для одного бота другую программу с polling/webhook. Один экземпляр агента и один отдельный браузерный профиль защищены локальной блокировкой.

## Команды Telegram

| Команда | Действие |
| --- | --- |
| `/status` | Состояние скрипта, количества вакансий и результат последнего поиска |
| `/clarifications` | Первые 20 вакансий на уточнение: название, причина и ссылка |
| `/clarifications 2` | Следующая страница списка уточнений; номер нужной страницы указан в ответе |
| `/history` | Последние 20 результатов |
| `/letter 123456` | Точное письмо, дополнения и подготовка |
| `/help` | Краткая справка |

Все команды только показывают данные. Старые `/search`, `/pause`, `/resume`, `/reconcile`, `/requeue`, `/queue` и `/settings` больше не управляют работой и подсказывают актуальные команды. Новые сообщения не содержат кнопок. Кнопки в ранее отправленных сообщениях уже не выполняют действий; при нажатии бот пробует убрать клавиатуру именно этого старого сообщения. Массовое удаление старых клавиатур недоступно: их номера сообщений ранее не сохранялись.

## Правила

- Python в направлении вакансии; удалённая работа, без командировок. Несовпадение технологий не блокирует отклик.
- 150 000 ₽ в месяц до налогов или на руки. Вилка подходит, если верхняя граница достигает порога. Без зарплаты нужен явно указанный Middle или выше; одних лет опыта недостаточно.
- Неизвестная валюта, период, неоднозначный грейд или географическое ограничение уходят на уточнение. Автоматического курса валют в этой версии нет.
- Видимое предложение пройти тест для вакансии приводит к пропуску. Тест не открывается. Общая реклама тестов и скрытые блоки не блокируют отклик.
- Неизвестные ответы на анкеты требуют участия пользователя.
- Используется только согласованное резюме `b424f687ff113123eb0039ed1f7a496e413267`. Профиль и видимость резюме не изменяются.
- Модель выбирает подходящие факты и до двух ограниченных утверждений о практическом знакомстве с технологиями из списка. Добавленные утверждения и подготовка показываются только владельцу. Карьерные факты не выдумываются и исходный профиль не меняется. Первая версия формирует письма на русском или английском из проверяемых фраз.

## Восстановление и границы версии

Перед отправкой заново читаются условия вакансии. Намерение отправить сохраняется до нажатия кнопки. После подтверждения сценарий завершается, даже если HH предлагает откликнуться повторно другим резюме. Контрольный отклик на вакансию `137924141` уже внесён как отправленный.

При обрыве связи во время отправки результат становится «неизвестен», а следующие отправки блокируются. При следующем запуске скрипт автоматически ищет явное подтверждение на странице вакансии. Отсутствие надписи не считается доказательством неотправленного отклика. Если подтверждения нет, нужно проверить историю HH вручную; автоматически повторить такой отклик нельзя. Поиск и подготовка других вакансий могут продолжаться, пока доступ к HH работает.

Капча, истёкший вход и неожиданная структура сайта останавливают затронутую работу. Остановите скрипт, при необходимости войдите через **scripts/setup.command**, затем снова запустите **scripts/start.command**. Не применяются обход капчи, скрытые методы HH или экспорт чужих браузерных сессий.

Поиск, чтение вакансий и отправка откликов идут через программный API hh.ru (как официальное мобильное приложение); браузер остаётся только запасным каналом для входа и редких форм. Поиск идёт по доступным страницам, при ограничении дополнительно разбивается по четырём диапазонам опыта. Если предел остаётся или выдача меняется, отчёт отмечает неполный охват. Это не обещание найти буквально все вакансии сайта. Первый поиск начинается при каждом запуске скрипта; по умолчанию повторный поиск — каждые 6 часов, между отправками — 90 секунд. Параметры находятся в `.env`.

Автоматически в Telegram приходят только подтверждённые успешные отклики с письмом и темами подготовки. Уточнения, ошибки и ежедневные сводки автоматически не отправляются. Ответы на текстовые команды приходят по запросу. Список вакансий, требующих решения, открывается командой `/clarifications`: по 20 записей на странице, с причиной и ссылкой. Ошибки и результаты доступны в `/history`, а состояние и текущая причина остановки — в `/status`. Пока скрипт выключен, бот не отвечает.

Анкеты с неизвестными ответами нужно заполнить вручную на HH. Чтение входящих сообщений работодателей и изменение их статусов в этой версии ещё не подключены. Сбой Telegram не останавливает поиск и отправку: уведомления об успешных откликах и ответы на команды остаются в очереди до восстановления связи. Редкий сбой после доставки может продублировать часть уведомления, но не сам отклик.

После длительного простоя Telegram может поменять последовательность ID обновлений. Если после недели бездействия бот перестал принимать команды, остановите приложение и повторите привязку через `pair`.

Проверки с реальным Chromium выполняются на подставных страницах, без запросов к HH. Формы и основные селекторы также сверены с живым HH через браузер. Автономная отправка именно этим приложением потребует отдельного запуска после настройки ключей и входа; ранее выполненный контрольный отклик был отправлен вручную через управляемый браузер.

## Запуск из терминала

```sh
cd /Users/vll/VLL/projects/job_finder_v2
.venv/bin/python -m job_finder init
.venv/bin/python -m job_finder configure
.venv/bin/python -m job_finder pair
.venv/bin/python -m job_finder api-login
.venv/bin/python -m job_finder login
.venv/bin/python -m job_finder doctor
.venv/bin/python -m job_finder run
```

Установка в новую папку на macOS/Linux с Python 3.12 или новее:

```sh
python3 -m venv .venv
.venv/bin/python -m pip install --upgrade pip
.venv/bin/python -m pip install -r requirements.lock
.venv/bin/python -m pip install -e . --no-deps
PLAYWRIGHT_BROWSERS_PATH=.cache/ms-playwright .venv/bin/python -m playwright install chromium
.venv/bin/python -m unittest discover -s tests
```

Секреты находятся в `.env`, сессия и база — в `.state/`; обе папки исключены из Git. Не публикуйте их и не удаляйте базу ради повторной отправки. Обновляя приложение, сохраняйте `.state/agent.sqlite3` вместе с файлами `-wal`/`-shm` либо делайте копию после остановки процесса.

История решений: [исходный проект](docs/superpowers/specs/2026-10-19-job-agent-design.md). Актуальные запуск и интерфейс Telegram описаны выше. Формат Telegram проверен по [официальному Bot API](https://core.telegram.org/bots/api); сохраняемый профиль браузера — по [документации Playwright](https://playwright.dev/python/docs/api/class-browsertype#browser-type-launch-persistent-context); запрос модели — по [официальному Chat Completions API](https://developers.openai.com/api/reference/resources/chat/subresources/completions/methods/create).
