# 10. Сводка ресёрча (docs/research)

Полные материалы лежат в [`docs/research/`](../research/) (отчёты, JSON-пробы, снимки) и в [`docs/superpowers/`](../superpowers/) (дизайн и план). Здесь — конспект выводов.

## Ключевой вывод: API hh.ru для соискателей закрыт

- В кабинете разработчика [dev.hh.ru/admin](https://dev.hh.ru/admin) прямо указано: **«поддержка API для соискателей прекращена 15 декабря 2025»**. Для регистрации доступны только приложения работодателей. ([проверка](../research/2026-10-19-hh-connectivity.md), [повторная проверка](../research/2026-10-21-hh-api-recheck.md))
- Публичная спецификация OpenAPI (SHA-256 `c465d0a45c61ad282f9627d09a927296700d1748e792aa72cb581481a063121e`): `GET /vacancies` и `GET /vacancies/{id}` описаны; `/resumes/mine`, `POST /negotiations`, операция `apply-to-vacancy` **отсутствуют**. У `/negotiations` только GET.
- Анонимные HTTP-пробы: поиск/детали вакансии/`/me` — 403; справочники и спецификация — 200. (403 сами по себе не доказывают удаление методов; вывод строится на уведомлении в кабинете.)
- Коммит в официальном репозитории (17.12.2025) удалил из README ссылки на собственные резюме и отклики соискателя.
- **Решение**: официальный API не используется как способ откликов; путь — публичный интерфейс сайта в браузере. Гибрид «API для поиска + браузер для отклика» допустим только при подтверждённом разрешённом доступе к поиску (у проекта его нет).

## Браузерная форма отклика (наблюдения)

Отчёт [2026-10-19-hh-browser-form.md](../research/2026-10-19-hh-browser-form.md):

- Кнопка «Откликнуться» на странице вакансии: `a[data-qa="vacancy-response-link-top"]`, ссылка `/applicant/vacancy_response?vacancyId=…&employerId=…`.
- В форме раскрывается список резюме: выбранное определяется **по значению radio-поля** (ID резюме), а не по названию (названия похожи).
- Поле письма: кнопка «Сопроводительное письмо Добавить» → `textarea[data-qa="vacancy-response-popup-form-letter-input"]`; счётчик «N из 10000».
- Кнопка отправки: `button[data-qa="vacancy-response-submit-popup"]`, текст «Откликнуться».
- Предупреждение о видимости резюме (`[data-qa="hidden-resume-warning"]`) может присутствовать в DOM, но быть свёрнуто (`max-height: 0`) — скрытый текст не блокирует форму.
- Текст «Для отклика необходимо ответить на несколько вопросов работодателя» может присутствовать без показа самих вопросов — не доказательство теста.
- Пример необходимости читать условия: вакансия Techno Diasoft `137921356` с меткой удалённой работы содержала ограничение Москвой/МО.

- Письмо 616 символов (факты резюме, без выдуманных утверждений) → после одного нажатия: «Вы откликнулись» → запись в истории (статус «Не просмотрен», 20→21) → полный текст письма в чате.

- Контрольный отклик `137924141` зафиксирован в базе как `sent`.

## Проверка реализации (21.10.2026)

Отчёт [2026-10-21-implementation-check.md](../research/2026-10-21-implementation-check.md):

- 80 тестов зелёные (теперь 133), из них 16 браузерных на настоящем Chromium с подменёнными страницами; остальные — временная SQLite и подменённый HTTP.
- Независимое ревью: 5 важных замечаний + 1 к сводке — все воспроизведены тестами и исправлены:
  1. прерывание генерации письма не оставляет блокирующую строку без письма;
  2. текст работодателя не считается подтверждением отправки;
  3. баннер теста распознаётся при разнесённых тексте и кнопке;
  4. Senior-наставник не повышает Junior-вакансию;
  5. удалённая вакансия с 404/410 не останавливает очередь;
  6. пропуски тестов не теряются между дневными сводками.
- На живом HH через управляемый браузер сверены селекторы (чтение, без новых отправок).
- Осознанные ограничения: нет чтения ответов работодателей, нет курсов валют, нет автоответов на анкеты; свобода формулировок писем ограничена проверяемыми фразами.

## Программный API вместо браузера (30.10.2026)

Отчёт [2026-10-30-hh-programmatic-api.md](../research/2026-10-30-hh-programmatic-api.md). Решение пользователя — убрать «человекоподобное» браузерное управление.

- Соискательский API **жив**: обслуживает официальное Android-приложение; доступен через OAuth2 с ключами приложения (эталон — [hh-applicant-tool](https://github.com/s3rgeym/hh-applicant-tool), протокол изучен по его исходникам и [архивной OpenAPI-доке](https://github.com/s3rgeym/hh-applicant-tool/blob/main/docs/hhapi/openapi.yml); код эталона не копировался).
- Анонимный публичный API по-прежнему 403 (проверено 30.10.2026 из этой сети).
- Рабочие эндпоинты: `GET /vacancies` (поиск, per_page=100, лимит 2000), `GET /vacancies/{id}`, `POST /negotiations` (отклик), `GET /negotiations` (подтверждение), `GET /me`, `/resumes/mine`.
- Реализовано в `hh_agent/hhapi.py`: OAuth-вход паролем или кодом SMS/email (RSA-OAEP trust-flags, капча в терминале), автопродление токена, API-источник с интерфейсом `Browser`. Браузер — запасной канал.
- Инварианты сохранены: claim до отправки, подтверждение по списку откликов, `unknown` без автоповтора, санитизация ошибок. 156 тестов зелёные; структура живой страницы входа сверена.
