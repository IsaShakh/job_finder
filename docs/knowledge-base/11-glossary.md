# 11. Глоссарий

## Термины домена

- **Вакансия (Vacancy)** — снимок страницы вакансии: ID, заголовок, описание, компания, зарплата, формат, наличие теста, статус закрытия, признак уже отправленного отклика, ключевые навыки.
- **Очередь** — таблица `jobs`: все обнаруженные вакансии с их статусами.
- **Статус** — этап жизненного цикла вакансии: `found`, `rejected`, `needs_clarification`, `ready`, `sending`, `sent`, `unknown`, `error`, `closed` (см. [04-data-model.md](04-data-model.md)).
- **Уточнение (needs_clarification)** — вакансия, решение по которой требует человека (неоднозначная зарплата/география/анкета); просматривается командой `/clarifications`.
- **Claim** — атомарная фиксация намерения отправить: `ready → sending` + строка в `attempts`, выполняется прямо перед кликом.
- **Evidence** — подтверждение отклика площадкой (надпись «Вы откликнулись» + URL страницы); без него статус `sent` не присваивается.
- **Unknown** — результат отправки неизвестен (обрыв после начала); требует ручной проверки истории HH, автоповтор запрещён.
- **Сверка (reconcile)** — проверка вакансий `unknown` на странице на предмет подтверждения отклика.
- **Просмотр (preview)** — режим по умолчанию (`HH_LIVE=false`): поиск, правила и письма работают, отправка выключена.
- **Live** — режим реальной отправки (`HH_LIVE=true`), включается только редактированием `.env` на компьютере.
- **AttentionRequired** — капча/выход из аккаунта/изменение структуры сайта: нужен человек; работа с HH останавливается (`browser_blocked`).
- **VacancyUnavailable** — HH отказывает в доступе к одной вакансии; локальная проблема, очередь продолжает работу.
- **Пилот/контрольный отклик** — вакансия `137924141` (At Prof), отправленная вручную 21.10.2026, внесена в БД как `sent`.
- **API-режим** — основной источник вакансий: программный HTTP-API hh.ru (OAuth мобильного приложения); включается наличием `.state/api-token.json`.
- **api-login** — команда входа в HH через API: пароль или код из SMS/письма, капча картинкой в терминале.
- **api-token.json** — локальный файл OAuth-токенов (0600) в `.state/`; access живёт ~2 недели, refresh одноразовый, продлевается автоматически.
- **negotiations** — отклики/переписка в API HH: `POST /negotiations` отправляет отклик, `GET /negotiations` служит подтверждением.
- **relations** — поле вакансии в API: наличие записей означает уже существующий отклик или отказ.
- **Дайджест (digest)** — ежедневная сводка очереди; доступна в базе/логах, проактивно в Telegram не шлётся.
- **Факты профиля** — проверяемые фразы из `profile.json` (резюме пользователя); единственный материал писем.
- **Добавленные утверждения (added_claims)** — ограниченные фразы о знакомстве с технологией (из закрытого списка) + план подготовки; видны только владельцу.
- **Fallback-письмо** — детерминированное письмо без LLM (нет ключа/модели).

## Сокращения

- **HH / hh.ru** — HeadHunter, сайт вакансий.
- **LLM** — языковая модель (OpenAI-совместимый Chat Completions endpoint).
- **WAL** — write-ahead logging (режим SQLite).
- **DRF** — Django REST Framework.
- **QA** — атрибут `data-qa`, стабильные селекторы hh.ru.
