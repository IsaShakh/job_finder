# 08. Эксплуатация: настройка, запуск, восстановление

## Первоначальная настройка

Зависимости уже установлены в папке проекта (`.venv`). Порядок для нового пользователя:

1. Открыть **scripts/setup.command** двойным щелчком (macOS). Токены и ключи в меню не вводятся — они задаются в файле **.env** (пример — `.env.example`).
2. **Ключи в `.env`**: `TELEGRAM_BOT_TOKEN` (токен бота от @BotFather), `TELEGRAM_OWNER_ID` (числовой ID владельца; узнать автоматически — `python -m job_finder pair`, альтернатива — @userinfobot и вписать вручную), `LLM_BASE_URL` (для OpenAI `https://api.openai.com/v1`), `LLM_API_KEY`, `LLM_MODEL` (задаётся явно). Интерфейс — Chat Completions с JSON-ответом. Без ключа модели работают поиск и черновики на основе фактов резюме. Интерактивный `configure` остаётся доступен в терминале как альтернатива.
3. **«Войти в HH (API, без браузера)»** (`api-login`): email или телефон HH + пароль, либо вход по одноразовому коду из SMS/письма. Капча показывается картинкой. Токен хранится в `.state/api-token.json` (0600) и продлевается автоматически; refresh-токен одноразовый, при долгом простое может понадобиться повторный вход. Запасной путь — «Войти в HH в браузере» (`login`): отдельный профиль браузера, вход вручную.
4. **scripts/start.command** или «Запустить агента»: поиск и обработка начинаются автоматически. Сначала действует **режим просмотра** (`HH_LIVE=false`): вакансии и письма сохраняются, отправка выключена.
5. Для реальных откликов: остановить приложение, в `.env` поставить `HH_LIVE=true`, запустить снова. Обязательны: ключ модели, Telegram, вход в HH. Telegram не переключает режим.

Источник вакансий выбирается автоматически: при наличии `.state/api-token.json` всё идёт через программный API (поиск, чтение, отклики, подтверждение); без него — через браузер.

Остановка: **Ctrl+C** в окне скрипта (или закрыть окно). Для продолжения — запустить снова.

## Команды CLI

```
cd /Users/vll/VLL/projects/job_finder_v2
.venv/bin/python -m job_finder init
.venv/bin/python -m job_finder configure
.venv/bin/python -m job_finder pair
.venv/bin/python -m job_finder api-login   # вход в HH через API (основной)
.venv/bin/python -m job_finder login       # запасной вход в браузере
.venv/bin/python -m job_finder doctor
.venv/bin/python -m job_finder run
.venv/bin/python -m job_finder status     # пауза и счётчики без запуска браузера
.venv/bin/python -m job_finder search     # один поиск, без отправки
```

`configure` и `pair` — необязательные помощники: все ключи и ID можно просто записать в `.env` вручную (см. `.env.example`).

## Параметры `.env` (см. [.env.example](../../.env.example))

| Переменная | По умолчанию | Смысл |
| --- | --- | --- |
| `TELEGRAM_BOT_TOKEN` | — | токен бота |
| `TELEGRAM_OWNER_ID` | 0 | ID владельца (заполняет `pair`) |
| `LLM_BASE_URL` | `https://api.openai.com/v1` | HTTPS endpoint Chat Completions |
| `LLM_API_KEY`, `LLM_MODEL` | — | ключ и модель (модель задаётся явно) |
| `HH_RESUME_ID` | согласованное | менять нельзя (валидация) |
| `HH_LIVE` | `false` | реальная отправка только через файл |
| `HH_HEADLESS` | `false` | скрытый браузер (кроме `login`) |
| `SEARCH_INTERVAL` | `21600` (6 ч) | период повторного поиска |
| `SEND_INTERVAL` | `90` | пауза между отправками, с |
| `MAX_SEARCH_PAGES` | `100` | предел страниц выдачи |

Переменные окружения терминала имеют приоритет над `.env`.

## Жизненный цикл запуска

1. Блокировка процесса → `store.recover()`.
2. Если есть `unknown` — автоматическая сверка (`reconcile`) по страницам вакансий; если подтверждений нет — отправки остаются заблокированными, поиск продолжается.
3. Первый поиск сразу, далее по `SEARCH_INTERVAL`.
4. Подготовка вакансий (`found → ready`), отправка по одной с интервалом `SEND_INTERVAL`.
5. Раз в день — сводка в outbox (доступна по командам; проактивно не шлётся).

## Восстановление после сбоев

| Ситуация | Поведение |
| --- | --- |
| Краш после отправки отклика | строка → `unknown`; при следующем запуске сверка: API — по списку откликов, браузер — по надписи на странице; без подтверждения — проверка истории HH вручную; автоповтор запрещён |
| Капча API | `AttentionRequired` → пауза + `browser_blocked`; открыть hh.ru вручную или подождать, перезапустить; при капче на входе — `api-login` с вводом капчи в терминале |
| Токен API истёк / не продлился | ошибка «выполните api-login» → `python -m job_finder api-login` |
| Изменилась структура страницы входа HH | `api-login` сообщает об изменении структуры; запасной путь — `login` через браузер |
| Вакансия недоступна конкретному аккаунту (403 «Вам недоступна эта вакансия») | `needs_clarification` только для этой вакансии; очередь продолжает работу |
| Вакансия закрыта/в архиве/404/410 | `closed`, очередь не блокируется |
| HH перенаправил отклик на форму (анкета/тест) | `needs_clarification` с причиной; ручной отклик на сайте |
| Достигнут дневной лимит откликов HH | `error` с причиной; работа продолжится на следующий день |
| Сбой Telegram | работа с HH продолжается; уведомления копятся в outbox до восстановления |
| Сбой генерации письма | статус `error`, повтор возможен; очередь не блокируется |
| Бот перестал принимать команды после недели простоя | остановить приложение, повторить `pair` |
| Второй экземпляр агента | отказ: «Агент уже запущен…» |

## Техническое обслуживание

- **Резервная копия**: `.state/agent.sqlite3` вместе с `-wal`/`-shm` (или копия после остановки процесса). Не удалять базу ради повторной отправки.
- **Обновление приложения**: сохранить `.state/`; установка в новую папку:

```sh
python3 -m venv .venv
.venv/bin/python -m pip install --upgrade pip
.venv/bin/python -m pip install -r requirements.lock
.venv/bin/python -m pip install -e . --no-deps
PLAYWRIGHT_BROWSERS_PATH=.cache/ms-playwright .venv/bin/python -m playwright install chromium
.venv/bin/python -m unittest discover -s tests
```

- **doctor** проверяет локально: токен, владелец, ключ+модель, профиль браузера, наличие Chromium. Сетевые проверки не выполняет.

## Типовые сценарии пользователя

- Посмотреть состояние и последний поиск → `/status`.
- Посмотреть, что требует решений → `/clarifications` (по 20 на странице).
- Посмотреть письмо конкретной вакансии → `/letter <ID>`.
- Решить «уточнение» вручную: открыть ссылку, действовать на hh.ru самостоятельно — приложение такие вакансии не трогает.
- Анкеты с неизвестными ответами заполняются вручную на HH; автоматической отправки с выдуманными ответами нет.
