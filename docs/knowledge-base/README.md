# База знаний проекта job_finder_v2 (job-finder)

Собрана 30 октября 2026 года по состоянию кода в рабочем дереве (последний коммит `66cacfe` + незакоммиченный рефакторинг «Telegram только для отчётов»).

Проект — **личный агент hh.ru**: поиск Python-вакансий, отбор по утверждённым правилам, генерация сопроводительных писем, очередь и отправка откликов через браузер, отчёты в Telegram.
