# Разведка Telegram-каналов с вакансиями (03.11.2026)

Проверка пяти каналов, выбранных пользователем, через публичные веб-превью `t.me/s/<name>` (этап 0.5 плана). Цель — подтвердить доступность, публичность, активность и пригодность формата постов для парсинга. Полная проверка текстов через MTProto-сессию — на этапе реализации адаптера.

**Вывод: в работе остаются четыре публичных активных канала.** Закрытых в списке нет — поддержка закрытых каналов остаётся требованием, но ни один из выбранных её не требует. `@jobhuntersapp` исключён пользователем (это бот-рассылка, а не канал). Архитектура «один адаптер на Telethon» сохраняется из-за требования закрытых каналов: MTProto покрывает и их, и публичные каналы одним механизмом (альтернатива `t.me/s` закрытые каналы не видит вообще).

## Наблюдения по форматам (влияют на адаптер)

1. **Зарплата** в тексте поста: «от 400000 ₽», «204000 - 325900 ₽», «от 300 до 450 тыс руб», «от 4 000 $ за месяц, на руки», «3000 - 4500 $» — парсится существующим `parse_salary` (правила: валюта ≠ RUB или период неясен → `needs_clarification`). Нужны мелкие расширения: «тыс руб», «на руки/до вычета» (gross/net — новое поле `salary_gross` из плана v2).
2. **Удалёнка**: у `@nopremote` в постах указан город (Москва и т.п.) — «remote» не гарантирован; у `@remotegeekjob` формат «Remote work (EMEA)», «(outside the US)» — удалёнка есть, но с **территориальными ограничениями** (поле `remote_geo` из плана v2); у `@pythonrabota`/`@job_python` — «Формат: удалённо/гибрид/офис».
3. **Компания**: почти всегда есть (или ссылка на hh.ru/employer). Нормализация названий (план, этап 3) критична для дедупа с hh.
4. **Реклама** в `@pythonrabota` и `@job_python`: образовательные промо, сервисы резюме, взаимопиар каналов. Признаки: маркеры «Реклама», ссылки на otus.ru/shortcut/updatecv.me, отсутствие вакансионных полей. Нужен детерминированный фильтр «не вакансия» в адаптере каналов.
5. **Посты без зарплаты** у `@remotegeekjob` — основная масса международных постов. По правилам текущего плана пройдут только с явным Middle+ в названии (Senior/Staff/Lead — таких много). Ожидаемая доля отсева — высокая; это согласовано с правилами (широкий охват вторичен по отношению к порогу 150k).
6. **Ссылки отклика**: nsprg.ru (редирект), talanto.work, jobs.lever.co и т.п. В карточку идёт ссылка на пост `t.me/<канал>/<id>`; дедуп по URL — только для ссылок вида `hh.ru/vacancy/<id>` (у `@nopremote` ссылка на вакансию hh есть не всегда — только employer).
7. **Язык**: `@remotegeekjob` — в основном английский (письмо на языке вакансии — уже поддержано), остальные — русский.

## Влияние на план

- Подтверждена архитектура: **один адаптер `telegram_channels` на Telethon** (диалоги аккаунта: каналы + боты-рассылки), список в конфиге `TG_CHANNELS`.
- В этап 3 добавить: дедуп по URL `hh.ru/vacancy/<id>` и `habr.com/.../vacancies/...` внутри текста поста.
- В этап 6 добавить: детерминированный фильтр рекламы/не-вакансий для каналов; расширения `parse_salary` («тыс руб», «на руки», валюты по курсу — политика валют из плана v2).
- Расчёт объёма: ~30–50 постов/день суммарно → после фильтра Python/удалёнки/зарплаты ожидается единицы подходящих в день; нагрузка на дедуп и LLM низкая.
