# Замеры источников: скорость и объёмы (03.11.2026)

Живые замеры для оценки длительности раунда поиска и потока уведомлений. hh в момент замера отдал 403 (токен истёк/отозван — нужен повторный `api-login`), поэтому цифры по hh — из констант кода (`MIN_REQUEST_INTERVAL=0.4 c`, `SEARCH_PER_PAGE=100`, лимит 2000, до 20 страниц на ветку, разбивка по 4 диапазонам опыта при переполнении).

## Скорость фидов (измерено)

| Источник | Ответ | Размер | Время | Примечание |
| --- | --- | --- | --- | --- |
| RemoteOK `/api` | 200 | 640 КБ JSON | ~7 с | весь каталог одним запросом (~5–10 тыс. вакансий) |
| We Work Remotely `/remote-jobs.rss` | 200 | 976 КБ | ~5,5 с | большой фид, полный текст в items |
| Habr Career `/vacancies/rss` | 200 | 43 КБ | ~1 с/страница | 25 вакансий на страницу; пагинация `?page=N&per_page=25` (прямой `/vacancies.rss` — 404) |
| Telegram-каналы (Telethon) | — | — | оценка 2–10 с | 4 канала × N последних постов |

## Оценка длительности одного раунда `/search`

- Поиск всех источников параллельно: **~10–90 с** (hh — узкое место: 0,4 с/запрос × до 20 страниц × 2 ветки «удалёнка + Москва»; худший случай с разбивкой по опыту — до 4 мин).
- Чтение новых вакансий: полнотекстовые фиды (RSS/RemoteOK/Telethon) приходят уже с текстом; читать нужно только **hh** — 0,4–1 с на новую вакансию.
- **Типичный ежедневный раунд: 1,5–3 минуты** (30–80 новых hh → 30–80 с чтения + ~30 с поиска).
- **Первый раунд на пустой базе: 10–25 минут** (до 2000 листингов hh, чтение 1000+ новых). Миграция текущей базы (1573 известных hh-записей) почти полностью снимает эту цену; RemoteOK вольётся одним запросом за секунды.

## Оценка потока уведомлений

| Источник | Новых за день (сырьё) |
| --- | --- |
| hh (удалёнка + Москва) | ~50–150 листингов |
| Habr RSS | ~10–30 |
| We Work Remotely | ~20–50 |
| RemoteOK | ~50–150 |
| 4 Telegram-канала | ~40–60 постов |
| **Итого сырья** | **~150–350** |

- Дедупликация снимает ~20–30% (каналы репостят hh/Habr).
- Правила — главный фильтр: на текущей базе проходило ~2–6% (1573 найдено → 31 письмо + 72 уточнения при старых, более строгих правилах). Новые правила мягче (Москва, «без грейда + Python-стек», intl без зарплатного порога).
- **Ожидаемо: 5–15 уведомлений за ежедневный раунд**; первый раз — до 30–100 (бэклог). Мера: `MAX_NOTIFY_PER_ROUND` (по умолчанию ~20, остальное — через `/history`) или первый прогон с `DELIVER=false`.

## Стоимость LLM за раунд

1 дешёвый вызов на прошедшую правилами вакансию: обычный раунд 5–15 вызовов (копейки, ~$0,01–0,05), первый раунд до $0,2–0,5. Эмбеддинги — только на новые вакансии (кэш в `job_embeddings`).

## Действие для пользователя

Токен hh истёк (403): перед живыми прогонами выполнить `scripts/setup.command` → «Войти в HH (API, без браузера)». После этого замеры по hh можно повторить точно.
