# Разведка кандидатов в Telegram-каналы (вторая волна источников, 06.11.2026)

Задача: `job_finder_v2-7uz`. Цель — проверить 9 «кандидатов из Excel»
файла `job_sources_python_ai_llm.md` и решить, какие добавить в `TG_CHANNELS`.

## Способ проверки

1. `scripts/tg_probe.py preview --channels ...` — публичные превью `t.me/s`
   без ключей. При проверке выяснилось, что **разметка t.me/s изменилась**
   (`data-post` переехал с `js-widget_message_wrap` на внутренний
   `js-widget_message`, у `<time>` поменялся порядок атрибутов) — старый
   парсер читал 0 постов с любого канала. Регулярки `BLOCK_RE`/`TIME_RE` в
   `scripts/tg_probe.py` обновлены; проверка на `nopremote` читает 20 постов.
2. Для каналов, невидимых через `t.me/s` (приватные), — Telethon-чтение
   `scripts/tg_probe.py read --channels ...` с существующей сессией
   `.state/tg_probe.session` (аккаунт пользователя). Каналы, которые сессия
   читает, доступны и адаптеру `telegram_channels` без доработок.

Фикстуры сохранены в `docs/research/fixtures/tg_channels/`:
`<канал>.preview.json` (t.me/s) и `<канал>.json` (Telethon).
